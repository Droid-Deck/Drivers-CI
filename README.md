# DroidDeck Drivers

Downloads for DroidDeck's Turnip drivers. Each release carries one all-in-one bundle and its checksum:

- `DD-Turnip-vX.Y.Z.zip`: the Android driver (`android/`) and the Linux ARM64 driver (`linux/`), indexed by `manifest.json`
- `DD-Turnip-vX.Y.Z.zip.sha256`

DroidDeck lists these under Components → GPU drivers → Manual, or import a downloaded zip there with **Import .zip**.
